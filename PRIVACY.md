# Privacy Policy

## ETL Expenses

This is a personal automation project for processing financial emails and receipts.

### Data Collection
- This application only accesses data from the authorized user's own Gmail account
- No data is collected from third parties
- No user data is stored on external servers beyond the user's own cloud infrastructure

### Data Usage
- Email data is processed solely for expense tracking automation
- Data is stored in the user's own BigQuery/S3 infrastructure
- No data is shared with third parties

### Security
- OAuth 2.0 is used for secure Gmail authentication
- All credentials are stored in AWS Secrets Manager
- No sensitive data is committed to this repository

### Contact
For questions about this privacy policy, please open an issue in this repository.
